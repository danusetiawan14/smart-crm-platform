# Smart CRM Platform

🚧 **Status:** Active Development

A modern Customer Relationship Management (CRM) platform built with Flask.

## Features

- User Authentication
- Dashboard
- Customer Management
- User Management
- Responsive UI

## Tech Stack

- Python
- Flask
- SQLAlchemy
- Bootstrap 5
- SQLite

## Roadmap

- Lead Management
- Sales Pipeline
- Email Integration
- Calendar
- REST API
- Analytics Dashboard

## Installation

```bash
pip install -r requirements.txt

python app.py
```
